# Paper repository

This repository holds the manuscript (TeX) only. No code, no data, no experiments.

Measurements, results and the research record live in `mvy0502/GenCP`, branch
`tubitak-tr`, under `tubitak/`. Read `tubitak/` for numbers; never re-derive a number
here. Every number that enters the manuscript must cite the gate or registration it
came from, and must state its inference path.

`mvy0502/gencp-validation` is a handover snapshot — do not treat it as the source of
record.
